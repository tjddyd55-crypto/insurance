# 1. 제품 개요

## 1-1. 목표
고객이 별도 고객 앱에서 매우 간단하게 파일과 메모를 올리면, 설계사 앱의 “청구 요청” 메뉴에 해당 요청이 자동으로 쌓이도록 만든다.  
동시에 설계사가 기존 시스템에 올리는 고객용 소식지를 연결된 고객 앱에서 그대로 볼 수 있게 하고, 새 소식 등록 시 푸시 알림이 가도록 만든다.

## 1-2. 이 제품이 해결하는 문제
현재 고객은 청구 서류를 카카오톡, 문자, 사진첩, 전화 등으로 분산 전달한다.  
이 방식은 누락, 혼선, 고객 식별 실패, 이력 관리 부재, 소식 전달 채널 부족의 문제가 있다.

이 앱은 다음을 해결한다.
- 고객이 누구인지 자동 식별
- 첨부 파일 누락 감소
- 설계사의 청구 요청 관리 일원화
- 설계사와 고객 사이의 고정 접점 확보
- 소식지/공지 전달 채널 확보

## 1-3. MVP 범위
### 고객 앱
- 설계사 링크로 최초 연결
- 고객/설계사/디바이스 연결 저장
- 청구 요청 생성
- 파일 첨부 업로드
- 요청 내역 확인
- 소식지 목록 보기
- 푸시 알림 수신

### 설계사 앱
- 고객별 연결 링크 생성
- 청구 요청 메뉴
- 요청 리스트 / 상세
- 상태 변경
- 고객용 소식지 등록
- 고객 앱과 연결된 발송 대상 관리

### 서버
- 링크 생성/연결 API
- 요청 생성/조회/상태 변경 API
- 파일 presign / 저장 API
- 고객 소식지 노출 API
- 푸시 발송 API
- 운영 로그

## 1-4. 절대 범위 밖
다음은 이번 개발 범위에 넣지 않는다.
- 보험사별 실제 청구 자동 접수/전송
- 보험사 외부 API 직접 연동
- 고객 회원가입 복잡화
- 고객용 아이디/비밀번호 로그인
- 설계사별 별도 앱 배포
- 채팅 기능
- 결제 기능
- 고객끼리 공유되는 커뮤니티 기능

## 1-5. 성공 기준
- 고객이 앱 설치 후 링크 연결만 하면 별도 입력 없이 요청 가능
- 설계사가 고객 식별 없이 바로 어떤 고객 요청인지 확인 가능
- 고객 첨부 파일이 누락 없이 연결된 요청에 매핑됨
- 설계사 소식지가 연결된 고객 앱에 자동 노출됨
- 앱 삭제/기기 변경 외에는 연결 유지됨
- 푸시가 너무 과도하지 않고 안정적으로 도착함
