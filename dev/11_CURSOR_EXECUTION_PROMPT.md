# 11. 커서 실행 지시문

아래 문구를 그대로 커서에 넣고 작업 시작한다.

---

## 커서 지시문

`dev/customer-claim-app-dev-package` 폴더의 문서를 1번부터 끝까지 순서대로 읽고 개발해라.

### 작업 원칙
- 기존 프로젝트 구조를 최대한 유지한다.
- 문서에 없는 범위까지 멋대로 확장하지 마라.
- 기존 설계사 앱의 다른 메뉴/권한/UI를 불필요하게 건드리지 마라.
- 고객 앱은 공용 하나만 만든다.
- 고객 앱 연결은 링크 기반으로 구현한다.
- 고객 식별은 반드시 `agent_id + customer_id + device_id` 조합으로 처리한다.
- 고객 로그인/회원가입/비밀번호 구조는 만들지 마라.
- 고객 요청 파일은 기존 스토리지와 prefix를 분리해 저장한다.
- 고객용 소식지는 기존 게시판 구조를 재사용 가능하면 재사용하되, 고객 노출 대상만 분리해라.
- 푸시는 마지막 단계에서 붙여라.

### 개발 순서
- `08_IMPLEMENTATION_STEPS.md`를 기준으로 STEP 1부터 순서대로 진행해라.
- 각 STEP 완료 시 아래 형식으로 보고해라.

#### 보고 형식
1. 이번 STEP에서 변경한 파일 목록
2. 구현한 내용 요약
3. 문서 기준으로 남은 TODO
4. 실행/빌드/테스트 결과
5. 리스크 또는 확인이 필요한 점

### 금지
- UI부터 먼저 만들지 마라.
- 문서에 없는 로그인 구조를 만들지 마라.
- 기존 앱 전체 레이아웃을 개편하지 마라.
- 테스트 없이 다음 STEP으로 넘어가지 마라.

### 최종 목표
- 고객 앱에서 링크 연결 후 파일 첨부와 요청 전송이 가능해야 한다.
- 설계사 앱에서 고객별 요청 리스트/상세/상태 변경이 가능해야 한다.
- 설계사 소식지가 고객 앱에 자동 노출되어야 한다.
- 푸시가 소식지 등록/상태 변경 시 정상 동작해야 한다.
