# 9. QA 체크리스트

## 9-1. 연결 관련
- [ ] 설계사 앱에서 고객별 링크 생성이 된다.
- [ ] 잘못된 customer_id로 링크 생성이 막힌다.
- [ ] 고객 앱 설치 후 링크 클릭 시 앱이 정상 실행된다.
- [ ] 연결 성공 시 설계사명/고객명이 정확히 표시된다.
- [ ] 앱 재실행 후에도 연결이 유지된다.
- [ ] 잘못된 링크는 정상적으로 실패 안내가 나온다.
- [ ] 앱 삭제 후 재설치 시 재연결이 필요하다.
- [ ] 폰 변경 시 재연결이 필요하다.

## 9-2. 파일 업로드
- [ ] 이미지 업로드 성공
- [ ] PDF 업로드 성공
- [ ] 허용되지 않은 파일 형식 실패
- [ ] 용량 초과 실패
- [ ] 업로드 실패 시 재시도 가능
- [ ] 업로드된 파일이 올바른 request에 연결된다.

## 9-3. 청구 요청
- [ ] 고객이 요청 생성 가능
- [ ] 요청 생성 후 설계사 앱에서 즉시 조회 가능
- [ ] 고객명/첨부 수/메모가 정확하다.
- [ ] 상태 변경이 정상 동작한다.
- [ ] 상태 이력이 남는다.
- [ ] 고객 앱에서 상태가 반영된다.

## 9-4. 소식지
- [ ] 고객용으로 등록한 글만 고객 앱에 보인다.
- [ ] 다른 설계사 글은 보이지 않는다.
- [ ] 읽음 처리 동작
- [ ] 중요 공지 표시(구현 시)
- [ ] 최신순 정렬 정상

## 9-5. 푸시
- [ ] 푸시 토큰 등록 성공
- [ ] 소식지 등록 시 푸시 수신
- [ ] 상태 변경 시 푸시 수신
- [ ] 중복 푸시 과도 발송 없음
- [ ] 푸시 실패 로그 확인 가능

## 9-6. 보안/권한
- [ ] 고객 앱이 다른 고객 데이터에 접근 불가
- [ ] 설계사가 본인 범위 외 고객 요청에 접근 불가
- [ ] 만료/비활성 링크 차단
- [ ] 파일 URL 접근 정책 점검

## 9-7. 운영
- [ ] 연결 로그가 남는다.
- [ ] 요청 생성 로그가 남는다.
- [ ] 상태 변경 로그가 남는다.
- [ ] 파일 orphan 정리 방안 존재
- [ ] 앱 버전 표시 가능
